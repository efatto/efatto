- Go to *Settings > Technical > Email > Incoming Mail Servers*.
- Leave *Create a New Record* empty to store the emails that no alias can
  route in *Settings > Technical > Email > Catch-all Mail*.
- Or set *Create a New Record* to a model: a record of that model is created
  only for the emails that would otherwise be discarded. Emails matching a
  mail alias keep being routed to their alias destination.

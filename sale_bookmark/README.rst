Configuration
=============

A quotation can be considered bookmarked for the customer if in a
specific state or marked manually by the user.

Default bookmark is when quotation is in ``sent`` state, to remove this
default delete the key ``sale.order.bookmark.state`` in configuration
parameters and mark manually the order with bookmarked flag.

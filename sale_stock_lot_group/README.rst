Configuration
=============

Nel lotto viene aggiunto un bottone per aprire gli ordini di vendita in cui è stato usato:

.. image:: https://raw.githubusercontent.com/efatto/efatto/18.0/sale_stock_lot_group/static/description/ordini_di_vendita.png
    :alt: Ordini di vendita

Questo collegamento avviene attraverso i movimenti di magazzino reali, quindi è irrilevante che sia stato selezionato nelle righe dell'ordine di vendita.
